# Airports: After Effects project

This folder builds the full, editable After Effects project for the airport motion graphic.
After Effects can only write `.aep` files itself, so the project is generated by a script that you run once in AE.

## Steps (about 5 minutes)

1. **Install the fonts** in `fonts/` (Montserrat Light, Regular, Medium). Double-click each one and choose Install.
   If you already have Montserrat from Google Fonts, you can skip this.
2. Open **After Effects** (any version from CC 2018 on) with a new, empty project.
3. Go to **File › Scripts › Run Script File…** and choose `Airports_Build_Project.jsx`.
   Keep `music.wav` in the same folder so the soundtrack is imported.
4. Wait while it builds. It creates about 470 layers, so it can take a few minutes. A message tells you when it's done.
5. **File › Save As** to save it as an `.aep` file.

If AE says scripts aren't allowed to write files, enable it in
*Edit/After Effects › Settings › Scripting & Expressions › Allow Scripts to Write Files and Access Network*.

## What you get

```
AIRPORTS/
├── AIRPORTS - MAIN         ← master comp, 38 s, 1920×1080, 30 fps (open this one)
├── Scenes/
│   ├── S01 Valley          jet climbs over a valley airport
│   ├── S02 Gate            empty gate, waiting rooms
│   ├── S03 Window          traveller at the window, take-off
│   ├── S04 Entrance        doors open, normal life pixel-dissolves, white-out
│   ├── S05 Clocks          world clocks spinning out of sync
│   ├── S06 3AM             night outside, the lights snap on
│   ├── S07 Sleepers        people sleeping on the floor
│   ├── S08 Noodles         ramen for breakfast at dawn
│   ├── S09 Coffee          coffee at midnight
│   └── S10 Concourse       busy concourse, day and night race past outside
└── Precomps/
    ├── Sxx … Exterior      the view through each window (sky, clouds, mountains, planes…)
    ├── S04 Normal Life     the street props that dissolve
    └── Departures Board    reusable flight board (plus a 03:00 version)
```

Each element is a separate native layer: sky bands, sun, clouds, mountains, skyline, control tower,
each plane, mullions, ceiling lights, floor, every seat row, every person, pillars, light rays, bokeh and every caption line.

### How it's animated (so you can edit it)

- **Camera:** every scene has a `CAMERA` null. Its **Pan** slider drives the parallax: each layer moves by
  Pan × its depth factor through a short position expression. Its **Scale** keyframes are the push-ins.
  Animate the one slider to change the camera move.
- **People:** walkers are rigged shape groups (thigh › shin, upper arm › forearm). The walk cycle is a
  `Math.sin(time …)` expression on each joint's rotation. Change the number after `time *` to change the pace.
- **Clocks, clouds, blinking lights, the 00:00 / 03:00 colon, breathing sleepers, floating "z"s:** expressions.
- **Captions:** text layers with a "Reveal" text animator (per-character fade-up). Edit the text freely.
- **Everything else** (plane flight paths, doors, cup, arm movements, white-out, lights switching on) is keyframed.
- **Look:** in the MAIN comp: `LOOK Bloom`, `LOOK Warm grade`, `LOOK Vignette`, `LOOK Grain`. Toggle or tweak them.
- **Voiceover:** the MAIN comp has a marker at each script line. Drop your VO in and line it up.

Tip: if you rename a scene comp, update the expressions in its `Exterior` precomp, which reference the scene comp by name
(`comp("S02 Gate").layer("CAMERA")`).
